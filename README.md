## ◈ System Overview

> *"I bridge the divide between theoretical AI research and deterministic production engineering. My objective is simple: design software systems where autonomous LLMs act as reliable, stateful execution engines rather than conversational toys."*

I am an **AI Systems Engineer** focused on building resilient, spec-driven applications. My engineering ethos prioritizes clean interfaces, state boundary isolation, deterministic routing, and measurable system latency before writing a single line of application code.

<table>
  <tr>
    <td width="50%" valign="top">
      <h3>⚡ Core Philosophy</h3>
      <ul>
        <li><b>Architecture Before Syntax:</b> Establish data contracts, schema models, and state graphs prior to feature implementation.</li>
        <li><b>Deterministic Agent Control:</b> Constrain stochastic model outputs with state machine supervisors, structured JSON schemas, and safety evaluation gates.</li>
        <li><b>Edge-First Inference:</b> Quantize and compile models for local on-device execution (&lt;20ms latency) whenever cloud round-trips can be avoided.</li>
        <li><b>Production Tenancy:</b> Enforce isolation across multi-user vector collections, tenant auth boundaries, and streaming pipelines.</li>
      </ul>
    </td>
    <td width="50%" valign="top">
      <h3>🎯 Target Domains</h3>
      <ul>
        <li><b>Agentic Systems:</b> Cyclic state graphs, supervisor-worker topologies, tool invocation, and human-in-the-loop flows.</li>
        <li><b>Enterprise RAG:</b> Dense + sparse hybrid search, per-user vector namespaces, dynamic reranking, and live web fallback.</li>
        <li><b>Edge Machine Learning:</b> INT8 post-training quantization, TFLite mobile runtimes, offline classification pipelines.</li>
        <li><b>Full-Stack AI Products:</b> High-throughput async backends (FastAPI), real-time SSE token streaming, modern UI (React/Vite).</li>
      </ul>
    </td>
  </tr>
</table>
