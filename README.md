## SELECTED WORK

<br>

### 01 &nbsp;///&nbsp; LEXIS
**Multi-Tenant Production RAG Knowledge Engine**

Enterprise documents · Isolated tenant namespaces · Sub-second token streaming.

* **Vector Isolation** — Strict collection partitioning in ChromaDB with Clerk JWT verification preventing cross-workspace data leaks.
* **Adaptive Grounding** — Real-time cosine similarity gating routes low-confidence queries directly to Tavily live web search fallback.
* **Low TTFT Pipeline** — Asynchronous FastAPI backend streaming real-time tokens via Groq Llama-3.

```
STACK: FASTAPI · REACT · NEON POSTGRES · CHROMADB · GROQ · CLERK
```

[ **VIEW REPOSITORY →** ](https://github.com/GhananilShirpurkar/Lexis)

<br><br>

### 02 &nbsp;///&nbsp; MEDISYNC
**Autonomous Pharmacy Multi-Agent Ecosystem**

Clinical workflow automation · Coordinated agent supervisor · Deterministic safety gates.

* **Supervisor State Graph** — LangGraph coordination across 5 specialized worker agents with dynamic conditional routing.
* **Clinical Quarantine Gates** — Hardcoded contraindication verification automatically halts execution on lethal drug interactions.
* **Multimodal Ingestion** — Combines Whisper voice dictation transcription with EasyOCR handwriting parsing models.

```
STACK: LANGGRAPH · FASTAPI · PYTORCH · WHISPER · EASYOCR · GROQ
```

[ **VIEW REPOSITORY →** ](https://github.com/GhananilShirpurkar/Medisync)

<br><br>

### 03 &nbsp;///&nbsp; SAFEGUARD-AI
**Sub-20ms On-Device Edge Scam Detection**

Mobile neural classification · On-chip INT8 inference · Zero-telemetry privacy.

* **On-Chip Inference** — Distilled classifiers converted to INT8 post-training quantized TFLite tensors running in &lt;20ms on mobile hardware.
* **Zero Telemetry** — Core phishing, SMS, and call classification operates 100% offline without external network dependencies.
* **Contextual Cloud Hybrid** — Selectively escalates to Gemini API only when edge scores flag nuanced multi-turn fraud.

```
STACK: ANDROID NATIVE · TFLITE INT8 · SCIKIT-LEARN · GEMINI API · KOTLIN
```

[ **VIEW REPOSITORY →** ](https://github.com/GhananilShirpurkar/SafeGuard-AI)
