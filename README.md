## About

I build **AI systems that solve real problems** — from agentic workflows and RAG platforms to production-oriented full-stack applications.

My work sits at the intersection of **applied AI and software engineering**, with a focus on:

* Agentic systems and multi-agent orchestration
* Retrieval-Augmented Generation
* LLM application architecture
* Production APIs and backend systems
* Full-stack AI products
* ML pipelines and on-device inference

I approach projects **system-first**: define the requirements, architecture, data flow, and interfaces before implementation.

> **Current build:** Lexis — a multi-chat RAG SaaS built with FastAPI, React, Clerk, Neon Postgres, Gemini embeddings, Groq, Tavily, and ChromaDB.

## Featured Projects

### Lexis

**Production-Grade Multi-Chat RAG SaaS**

> A full-stack Retrieval-Augmented Generation platform designed as a deployable AI knowledge product rather than a prototype.

**Stack:** FastAPI · React · Vite · Clerk · Neon Postgres · ChromaDB · Gemini · Groq · Tavily · SQLAlchemy · Alembic

**Architecture**

* Multi-user and multi-workspace architecture
* Per-user / per-collection vector isolation
* Gemini-powered document embeddings
* ChromaDB vector storage
* Optional live web augmentation through Tavily
* Groq-powered response generation
* Streaming responses
* Clerk JWT authentication
* Async Python backend

**Repository**

[![GitHub](https://img.shields.io/badge/GitHub-GhananilShirpurkar%2FLexis-1e293b?style=flat-square\&logo=github)](https://github.com/GhananilShirpurkar/Lexis)

### MediSync

**Multi-Agent Pharmacy Automation System**

> An AI-powered pharmacy workflow built around coordinated specialized agents for prescription processing, drug interaction checking, inventory management, and communication.

**Stack:** LangGraph · FastAPI · React · EasyOCR · Whisper · PyTorch · Groq

**Architecture**

* 5+ specialized agents
* Supervisor-worker architecture
* Event-driven agent communication
* Conditional LangGraph routing
* Parallel agent execution
* Isolated agent state
* Structured inter-agent outputs
* Role-based access

**Repository**

[![GitHub](https://img.shields.io/badge/GitHub-GhananilShirpurkar%2FMediSync-1e293b?style=flat-square\&logo=github)](https://github.com/GhananilShirpurkar/MediSync)

### SafeGuardAI

**On-Device Android Scam Detection**

> An Android application combining an on-device TFLite classifier with Gemini-powered contextual explanations for SMS and call scam detection.

**Stack:** Android · TFLite · Gemini API · Python · scikit-learn

**Architecture**

* On-device classification
* INT8 quantized TFLite model
* Sub-20ms inference target
* No server dependency for core classification
* Privacy-first processing
* Complete ML pipeline from data to deployment

**Repository**

[![GitHub](https://img.shields.io/badge/GitHub-GhananilShirpurkar%2FSafeGuardAI-1e293b?style=flat-square\&logo=github)](https://github.com/GhananilShirpurkar/SafeGuardAI)
