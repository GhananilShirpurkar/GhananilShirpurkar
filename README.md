## 🚀 Flagship Engineering Systems

### 01 // LEXIS — Production Multi-Chat RAG SaaS Platform
<p>
  <b>A deployable multi-tenant knowledge engine engineered for zero cross-tenant contamination and sub-second token streaming.</b>
</p>

<p>
  <img src="https://img.shields.io/badge/FastAPI-009688?style=flat-square&logo=fastapi&logoColor=white" alt="FastAPI" />
  <img src="https://img.shields.io/badge/React%20%2F%20Vite-61DAFB?style=flat-square&logo=react&logoColor=black" alt="React" />
  <img src="https://img.shields.io/badge/ChromaDB-FF6F00?style=flat-square&logo=databricks&logoColor=white" alt="ChromaDB" />
  <img src="https://img.shields.io/badge/Groq%20LPU-F55036?style=flat-square&logo=lightning&logoColor=white" alt="Groq" />
  <img src="https://img.shields.io/badge/Neon%20Postgres-00E599?style=flat-square&logo=postgresql&logoColor=black" alt="Neon Postgres" />
  <img src="https://img.shields.io/badge/Clerk%20Auth-6C47FF?style=flat-square&logo=clerk&logoColor=white" alt="Clerk" />
</p>

- 🛡️ **Zero-Leakage Multi-Tenancy:** Partitioned ChromaDB collections per workspace guarded by Clerk JWT session verification.
- 🌐 **Adaptive Live Grounding:** Real-time cosine distance gating routes low-scoring queries (<0.72) directly to Tavily live web search.
- ⚡ **Low TTFT Token Streaming:** Asynchronous FastAPI streaming pipeline delivering real-time Server-Sent Events (SSE) via Groq Llama-3.
